MALEGAON EXPLORING — SEO ASSIGNMENT SITE

Includes homepage, 10 individual HTML article pages, unique titles and meta descriptions, responsive style.css, sitemap.xml, robots.txt, and 10 local SVG starter illustrations. All files are in one flat folder.

DEPLOY:
1. Extract this ZIP.
2. Create a public GitHub repository with README disabled.
3. Upload every extracted file directly to the repository root (not a nested folder).
4. Import the repository into Vercel. Framework preset: Other.
5. After deployment, replace YOUR-SITE.vercel.app with your real Vercel hostname in index.html, all post pages, sitemap.xml, and robots.txt; commit changes.
6. In Google Search Console, add the URL-prefix property, complete verification, submit sitemap.xml, and request indexing for the homepage.

IMAGE NOTE:
Included SVGs are original local starter illustrations, not downloaded photographs. If your instructor specifically requires real photos, replace each SVG with a licensed photo renamed to match the referenced filename, or update image paths consistently.
